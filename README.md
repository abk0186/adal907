# ADAL MODEL 907

Продающий одностраничный сайт мини-погрузчика ADAL MODEL 907. Статика для GitHub Pages: `index.html` и папка `assets`, без бэкенда. Язык — русский.

## Локально

Модули three.js не открываются как `file://`. Нужен обычный HTTP-сервер из корня репозитория:

```bash
python3 -m http.server 8765
```

Сайт: http://127.0.0.1:8765/

## GitHub Pages

Репозиторий уже рассчитан на публикацию **из ветки `main`, папка `/` (root)**.

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В блоке **Build and deployment** выберите **Deploy from a branch**.
3. **Branch:** `main`, **Folder:** `/ (root)`.
4. Сохраните. Через минуту-две сайт откроется по адресу  
   https://abk0186.github.io/adal907/

Файл `.nojekyll` в корне отключает обработку Jekyll, чтобы Pages отдал `assets` как есть.

Если подключите свой домен, замените абсолютные адреса в `og:image`, `og:url` и `canonical` в `index.html` (сейчас там адрес GitHub Pages этого репозитория).

## Что на странице

- Первый экран: интерактивная 3D-модель на three.js (мышь и палец, масштаб, медленное вращение в покое). Кнопки «Поднять ковш» и «Излом рамы». Без WebGL показывается фото.
- Характеристики только подтверждённые: 500 кг, выгрузка 2,9 м, Changjia CJ32M 25 л.с., шарнирная рама, ковш около 0,3 м³, дополнительный радиатор, гидравлика под навесное. Сенозахват в комплект не входит.
- Цена — по запросу. Звонок `tel:+77003330999` и WhatsApp `https://wa.me/77003330999`. Форма открывает WhatsApp с текстом заявки.
- Цвет серии — графит. Оранжевые фото подписаны как заводской образец.

Исходники тяжелее отобранных файлов в `assets/` в репозиторий не входят. Кадры с надписью «Bending Arm King» не используются.
