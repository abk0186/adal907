# ADAL MODEL 907

Продающий одностраничный сайт мини-погрузчика ADAL MODEL 907. Статика для GitHub Pages: `index.html` и папка `assets`, без бэкенда. Язык — русский.

## Локально

Страница открывается и как файл, и через локальный сервер из корня репозитория:

```bash
python3 -m http.server 8765
```

Сайт: http://127.0.0.1:8765/

## GitHub Pages

Репозиторий уже рассчитан на публикацию **из ветки `main`, папка `/` (root)**.

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В блоке **Build and deployment** выберите **Deploy from a branch**.
3. **Branch:** `main`, **Folder:** `/ (root)`.
4. Сохраните. Через минуту-две сайт откроется по адресу  
   https://abk0186.github.io/adal907/

Файл `.nojekyll` в корне отключает обработку Jekyll, чтобы Pages отдал `assets` как есть.

Если подключите свой домен, замените абсолютные адреса в `og:image`, `og:url` и `canonical` в `index.html` (сейчас там адрес GitHub Pages этого репозитория).
